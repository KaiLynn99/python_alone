- テーブルや列の確認

## 2. DAX（Data Analysis Expressions）

- Power BIでデータを`計算・分析するための数式言語`。
- DAXは、すでに読み込まれているデータモデルを基準に`分析値を計算`するときに使用する。
-` 列またはテーブルを参照`して数式を作成する。
- データ分析に使用できるさまざまな関数を提供する。

<img src="images/image-7.png" width="550">

#### 1) DAX構文

```sql
名前 = 関数(テーブル名[列名])
```

例：

```sql
総売上 = SUM('販売'[売上])
```

```sql
総売上 → 新しく作成するメジャー名
= → 数式の開始
SUM() → 関数
'販売'[売上] → テーブルの特定の列
```

#### 2) DAX演算子

実務でよく使用する演算子を中心に整理する。

| 種類 | 演算子 | 意味 | 例 |
|---|---|---|---|
| 算術 | `+` | 加算 | `[売上] + [追加額]` |
|  | `-` | 減算 | `[売上] - [原価]` |
|  | `*` | 乗算 | `[単価] * [数量]` |
|  | `/` | 除算 | `[売上] / [数量]` |
| 比較 | `=` | 等しい | `[地域] = "東京"` |
|  | `<>` | 等しくない | `[地域] <> "東京"` |
|  | `>` | より大きい | `[売上] > 1000000` |
|  | `<` | より小さい | `[売上] < 1000000` |
|  | `>=` | 以上 | `[売上] >= 1000000` |
|  | `<=` | 以下 | `[売上] <= 1000000` |
| 論理 | `&&` | AND（両方の条件を満たす） | `[売上] > 1000000 && [地域] = "東京"` |
|  | `\|\|` | OR（いずれかの条件を満たす） | `[地域] = "東京" \|\| [地域] = "大阪"` |
|  | `NOT` | 条件を否定する | `NOT([地域] = "東京")` |
| 文字列 | `&` | 文字列を連結する | `[姓] & [名]` |

## 3. 新しいメジャーと新しい列(計算列)

Power BIでは、テーブルに新しい値を追加する方法として `新しいメジャー`と`新しい列` がある。

<img src="images/image-8.png" width="550">

---

#### 1) メジャー（Measure）

SQLの`集計関数`のように、`列を参照して合計・平均・件数などを動的に計算する`。

- テーブルに新しい列は追加されず、計算結果も行ごとの値として保存されない
- フィルターやビジュアルで設定された項目に応じて、計算結果が変わる
- 主にビジュアルの「値」に使用する
- 計算列よりデータサイズへの影響が小さい

例：総売上を計算

```sql
総売上 = SUM('販売'[販売金額])
```
→ 現在のフィルター条件に応じた販売金額の合計を求める。

#### - メジャーの確認

作成したメジャーは「`データ`」ペインで確認できる。

- メジャーの前には電卓アイコンが表示される
- 実際の計算結果はレポートのビジュアルに配置して確認する

<img src="images/image-9.png" width="200">

※ SQLでは `GROUP BY` と集計関数を使って集計するが、DAXのメジャーは `フィルターコンテキストに応じて動的に再計算される`。

---

#### 2) 計算列（Calculated Column）

SQLの`単一行関数`のように、`各行ごとに数式を計算して結果を保存する`。

- テーブルに新しい列を追加
- 行単位で計算
- 軸・凡例・値などに使用可能
- データセットのサイズが増加する

例：利益を計算

```sql
利益 = '販売'[販売金額] - '販売'[原価]
```

→ 各行ごとに `販売金額 - 原価` を計算する。

<img src="images/image-10.png" width="650">

---

#### - 計算列とメジャーの使い分け

- `レポート上で条件に応じて集計結果を変化させたい` → メジャー
- `行ごとに値が必要` → 計算列

---

→「`データ`」ペインから `総売上` メジャーをカードの「**値**」にドラッグ＆ドロップする。

→ `総売上` の集計結果をカード上で確認できる。

<img src="images/image-11.png" width="250">

<img src="images/image-12.png" width="250">



※「`カテゴリ`」に `地域` を追加すると地域別、`商品` を追加すると商品別に集計結果が変化する。

- メジャーはデータビューで行ごとの値を確認するのではなく、`レポート上のビジュアルに配置して確認する`
- フィルターや行・列などの条件に応じて、`メジャーの計算結果は動的に変化する`

<img src="images/image-13.png" width="450">

#### ※ SQLとの比較

- `値` → 集計関数の結果
- `カテゴリ` → `GROUP BY`の項目
- `SQL`は集計項目に合わせてクエリを変更するが、`DAX`はビジュアルの項目を変えるだけで集計できる

キャンバスに`テーブル`ビジュアルを追加すると、SQLの`GROUP BY`の結果のように集計結果を確認できる。

<img src="images/image-14.png" width="500">

- 1つの総売上だけでなく、商品別の総売上と全体の合計を確認できる

---

#### 5) メジャー vs 計算列

| 区分 | メジャー | 計算列 |
|---|---|---|
| 計算タイミング | ビジュアルの表示時 | データ更新時 |
| 計算単位 | `フィルターされたデータ` | `行単位` |
| 結果 | 必要なときに計算 | 各行に値を保存 |
| 代表例 | SUM(売上) | 数量 × 単価 |
| データサイズ | モデルサイズへの影響が小さい | `列が追加される` |
| 主な用途 | `集計、KPI、分析` | `分類、派生列` |
| 代表的な関数 | `SUM`、`AVERAGE`、`COUNTROWS` | `IF`、`SWITCH`、`YEAR` |

---

#### 6) メジャーを追加し、ビジュアルで確認

- `総売上`

総売上 = SUM('販売'[販売金額])

- `総原価`

総原価 = SUM('販売'[原価])

- `総数量`

総数量 = SUM('販売'[数量])

- `平均販売金額`

平均販売金額 = AVERAGE('販売'[販売金額])

- `注文件数`

注文件数 = COUNTROWS('販売')

→ SQLの`COUNT(*)`と同様

- `顧客数`

顧客数 = DISTINCTCOUNT('販売'[顧客])

→ 重複を除いてカウント

<br>

「`カード`」ビジュアルを使用して各メジャーを確認する。

#### ※ メジャー管理テーブルの作成

メジャーは集計値のため、テーブル上ではなく「`データ`」ペインで確認する。
Power BIでは、メジャーを専用のテーブルにまとめて管理できる。

1. 「**データの入力**」から新しいテーブルを作成する
2. テーブル名を `_メジャー` に変更する
   - `_` は通常のデータテーブルと区別するための接頭辞
3. 不要な自動生成列は「**データ**」ペインで非表示にする
4. 「**データ**」ペインからメジャーを選択する
5. 「**メジャーツール（Measure tools）**」→「**ホームテーブル（Home table）**」を選択する
6. ホームテーブルを `_メジャー` に変更する
